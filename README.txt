РАУНД НЕ НАЙДЕН — ПРОБНИК 0.4

index.html — общий экран и подключение игроков с телефонов через PeerJS.
audio/ — ваши MP3; музыка переключается по типу раунда. Альтернативные версии сохранены в audio/alternates/.
images/hosts/ — шесть образов ФРАЗиКа с прозрачным фоном.
images/avatars/ — десять аватаров игроков с прозрачным фоном.
images/scene.png — фон сцены.

Запуск:
1. Распакуйте архив целиком.
2. Откройте index.html в современном браузере.
3. Для подключения телефонов требуется интернет (PeerJS CDN и публичная инфраструктура PeerJS).
4. На общем экране нажмите «Музыка» один раз — браузер разрешит воспроизведение; дальше треки меняются автоматически.
5. Игроки вводят код комнаты на телефонах и выбирают аватары.

В этой сборке оставлены пять режимов:
- Кто здесь гусь? — один игрок получает похожий, но другой вопрос.
- Мой ответ — придумать ответ и найти настоящий.
- Похоже, но разное — один игрок получает близкое, но отличающееся задание для рисунка; авторы скрыты до результата.
- А как ответит он? — угадать число другого игрока.
- Блиц — пять быстрых вопросов.
